
UI设计，编辑与显示需要区分开，Eye图标表示UI显示，Pen图标表示编辑内容。

公文编辑格式说明：
UI显示内容为md格式，使用#来表示标题级别
行首 # 表示为标题；
行首 ## 表示为以及标题；
行首 ### 表示为三级标题；
行首 #### 表示为四级标题；
行首无 # 表示为正文内容。

公文显示格式要求：
按照编辑格式中的要求，显示时需要将标题和正文区分开，标题使用标题样式，正文使用正文样式，#符号仅仅标记正文与标题，不显示在最终显示结果中。
标题：2号方正小标宋简体，分多行时采用梯形或菱形排列，要求居中显示。
正文：3号仿宋GB2312，每行28字、每页22行，行距固定值28.9磅，每段首行缩进2字符。
一级标题：黑体三号，序号“一、”，要求悬挂两字。
二级标题：楷体GB2312三号，序号“（二）”，要求悬挂两字；
三、四级标题：仿宋GB2312三号，序号“3.”和“（4）”，要求悬挂两字符。
数字：全文统一使用Times New Roman字体，成文日期用阿拉伯数字（如“2025年7月3日”）。
