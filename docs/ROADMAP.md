# Refantastic 开发路线图

本文档记录了 Refantastic 智能公文生成系统的开发计划和进度。

## 📋 版本规划

### Phase 1: MVP（已完成） ✅

核心功能实现，验证技术可行性。

- [x] **向量知识库**
  - 基于 ChromaDB 的向量存储
  - Sentence Transformers 嵌入模型集成
  - 语义相似度检索
  
- [x] **RAG 引擎**
  - 文档检索与上下文构建
  - Prompt 工程
  - LLM 集成（OpenAI）
  
- [x] **基础生成 API**
  - FastAPI 框架搭建
  - 公文生成接口
  - 参考文档搜索接口
  
- [x] **文档检索**
  - 混合检索（语义+关键词）
  - 按文档类型过滤
  - 相似度排序

**里程碑**：2025 Q1
**状态**：已完成

---

### Phase 2: 核心功能（进行中） 🚧

完善业务功能，支持实际应用场景。

- [ ] **模板管理系统**
  - 模板创建、编辑、删除
  - 模板分类和标签
  - 模板变量替换
  - 模板版本控制
  
- [ ] **审批工作流**
  - 可配置的多级审批流程
  - 审批状态跟踪
  - 审批意见记录
  - 邮件/消息通知
  
- [ ] **合规检查引擎**
  - 敏感词过滤
  - 格式规范校验
  - 法规条款对照
  - 政策合规性检查
  
- [ ] **用户权限系统**
  - JWT 身份认证
  - RBAC 权限控制
  - 部门/角色管理
  - 操作审计日志
  
- [ ] **前端界面**
  - React/Vue 框架选型
  - 富文本编辑器集成
  - 响应式设计
  - 文档预览和导出

**里程碑**：2025 Q2
**状态**：进行中
**优先级**：高

---

### Phase 3: 增强功能 📈

提升用户体验，扩展应用场景。

- [ ] **多轮对话编辑**
  - 对话式文档优化
  - 增量修改建议
  - 上下文保持
  - 修改历史记录
  
- [ ] **批量生成**
  - 批量任务提交
  - 异步处理队列
  - 进度跟踪
  - 结果打包下载
  
- [ ] **知识图谱集成**
  - 实体关系抽取
  - 知识图谱构建
  - 图谱可视化
  - 基于图谱的推理
  
- [ ] **移动端支持**
  - 移动端适配
  - 小程序/App 开发
  - 离线编辑
  - 语音输入
  
- [ ] **外部系统集成**
  - OA 系统对接
  - 电子印章集成
  - 文件管理系统集成
  - 第三方存储支持

**里程碑**：2025 Q3
**状态**：计划中
**优先级**：中

---

### Phase 4: 企业级 🏢

面向大规模部署，提供企业级保障。

- [ ] **高可用部署**
  - 微服务架构改造
  - 负载均衡
  - 服务降级和熔断
  - 灰度发布
  
- [ ] **监控告警**
  - 性能监控（Prometheus）
  - 日志聚合（ELK）
  - 链路追踪（Jaeger）
  - 智能告警
  
- [ ] **数据备份恢复**
  - 自动备份策略
  - 增量备份
  - 快速恢复
  - 灾难恢复演练
  
- [ ] **审计报表**
  - 使用统计分析
  - 合规审计报告
  - 自定义报表
  - 数据导出
  
- [ ] **性能优化**
  - 数据库查询优化
  - 缓存策略优化
  - CDN 加速
  - GPU 推理加速

**里程碑**：2025 Q4
**状态**：计划中
**优先级**：中
