### 问题1
##### 问题描述
SQLAlchemy保留了属性名metadata，所以定义的KnowledegeDocument模型不能重复定义该属性，
可以修改为`_metadata`,相应的,其他模型定义的属性也需要进行修改。
`sqlalchemy.exc.InvalidRequestError: Attribute name 'metadata' is reserved when using the Declarative API.`

### 问题3 huggingface的transformers库的版本问题
##### 问题描述

`ImportError: cannot import name 'cached_download' from 'huggingface_hub' (D:\Programs\Anaconda3\envs\uah\Lib\site-packages\huggingface_hub\__init__.py)`
这个问题是因为vector_store中需要利用huggingface去管理向量化模型，所以导入了SentenceTransformer,如果本地不需要向量化可以隔离开这个错误。
