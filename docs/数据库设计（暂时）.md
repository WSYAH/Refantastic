## 设计原则

1. **数据一致性**：使用外键约束保证引用完整性
2. **扩展性**：使用 JSON 字段存储灵活的元数据
3. **性能优化**：在常用查询字段上建立索引
4. **审计追踪**：记录创建时间、更新时间等审计信息
5. **软删除**：重要数据使用状态字段标记删除，支持恢复

## 详细设计

### 知识库模块

#### 1. knowledge_documents（知识库文档表）

存储所有上传到知识库的文档，支持向量化检索。

**表结构**

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| `id` | VARCHAR(36) | PRIMARY KEY | 文档唯一标识（UUID） |
| `title` | VARCHAR(500) | NOT NULL, INDEX | 文档标题 |
| `content` | TEXT | NOT NULL | 文档内容 |
| `doc_type` | VARCHAR(100) | NOT NULL, INDEX | 文档类型（通知、报告等） |
| `author` | VARCHAR(200) | NULL | 作者 |
| `department` | VARCHAR(200) | NULL | 部门 |
| `tags` | JSON | DEFAULT [] | 标签列表 |
| `keywords` | JSON | DEFAULT [] | 关键词列表 |
| `file_path` | VARCHAR(1000) | NULL | 原始文件路径 |
| `file_type` | VARCHAR(50) | NULL | 文件类型（pdf、docx等） |
| `file_size` | INTEGER | NULL | 文件大小（字节） |
| `is_vectorized` | BOOLEAN | DEFAULT FALSE, INDEX | 是否已向量化 |
| `vector_id` | VARCHAR(100) | NULL | 向量库中的ID |
| `embedding_model` | VARCHAR(200) | NULL | 使用的嵌入模型 |
| `quality_score` | INTEGER | DEFAULT 0 | 质量评分（0-100） |
| `view_count` | INTEGER | DEFAULT 0 | 浏览次数 |
| `reference_count` | INTEGER | DEFAULT 0 | 引用次数 |
| `status` | VARCHAR(50) | DEFAULT 'active' | 状态（active、archived、deleted） |
| `is_public` | BOOLEAN | DEFAULT TRUE | 是否公开 |
| `created_at` | DATETIME | NOT NULL | 创建时间 |
| `updated_at` | DATETIME | NOT NULL | 更新时间 |
| `vectorized_at` | DATETIME | NULL | 向量化时间 |
| `metadata` | JSON | DEFAULT {} | 额外元数据 |

**索引**

```sql
CREATE INDEX idx_knowledge_doc_title ON knowledge_documents(title);
CREATE INDEX idx_knowledge_doc_type ON knowledge_documents(doc_type);
CREATE INDEX idx_knowledge_doc_vectorized ON knowledge_documents(is_vectorized);
CREATE INDEX idx_knowledge_doc_status ON knowledge_documents(status);
CREATE INDEX idx_knowledge_doc_created ON knowledge_documents(created_at);
```

**JSON 字段结构**

```json
// tags 字段示例
["工作会议", "年度总结", "通知类"]

// keywords 字段示例
["会议", "参加", "2024年"]

// metadata 字段示例
{
  "filename": "2024年度工作通知.pdf",
  "file_extension": "pdf",
  "file_hash": "a1b2c3d4e5f6",
  "image_count": 2,
  "table_count": 1,
  "has_images": true,
  "has_tables": true,
  "extraction_info": {
    "text_length": 1500,
    "table_format": "markdown"
  }
}
```

### 文档管理模块

#### 3. documents（公文文档表）

存储生成的公文文档。

**表结构**

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| `id` | VARCHAR(36) | PRIMARY KEY | 文档ID |
| `title` | VARCHAR(500) | NOT NULL | 文档标题 |
| `content` | TEXT | NOT NULL | 文档内容 |
| `doc_type` | VARCHAR(100) | NOT NULL | 文档类型 |
| `doc_number` | VARCHAR(100) | UNIQUE | 文号 |
| `status` | VARCHAR(50) | DEFAULT 'draft' | 状态（draft、reviewing、approved、published、archived） |
| `creator_id` | VARCHAR(36) | NOT NULL, FK | 创建人ID |
| `approver_id` | VARCHAR(36) | NULL, FK | 审批人ID |
| `template_id` | VARCHAR(36) | NULL, FK | 使用的模板ID |
| `workflow_instance_id` | VARCHAR(36) | NULL, FK | 工作流实例ID |
| `tags` | JSON | DEFAULT [] | 标签 |
| `attachments` | JSON | DEFAULT [] | 附件列表 |
| `version` | INTEGER | DEFAULT 1 | 版本号 |
| `is_public` | BOOLEAN | DEFAULT FALSE | 是否公开 |
| `published_at` | DATETIME | NULL | 发布时间 |
| `expires_at` | DATETIME | NULL | 过期时间 |
| `created_at` | DATETIME | NOT NULL | 创建时间 |
| `updated_at` | DATETIME | NOT NULL | 更新时间 |
| `metadata` | JSON | DEFAULT {} | 元数据 |

**外键约束**

```sql
FOREIGN KEY (creator_id) REFERENCES users(id) ON DELETE RESTRICT
FOREIGN KEY (approver_id) REFERENCES users(id) ON DELETE SET NULL
FOREIGN KEY (template_id) REFERENCES templates(id) ON DELETE SET NULL
FOREIGN KEY (workflow_instance_id) REFERENCES workflow_instances(id) ON DELETE SET NULL
```

**状态流转**

```
draft（草稿） → reviewing（审核中） → approved（已批准） → published（已发布） → archived（已归档）
              ↓
           rejected（已拒绝）
```
